# Покебол

Сайт строительной компании с оригинальной концепцией сферических домов, сервером Node.js, MongoDB и закрытым кабинетом заявок. Визуалы — авторские концепты, не копия графики известных франшиз.

## Что подключить

### 1. MongoDB Atlas

1. Создайте кластер и отдельного пользователя базы данных.
2. Разрешите сетевой доступ к Render. Если у тарифа нет фиксированных исходящих IP, настройте доступ с учётом этого ограничения; используйте длинный пароль базы и пользователя с правами только на базу приложения.
3. Скопируйте строку подключения `mongodb+srv://...` и подставьте имя базы, например `pokebol`.

Не добавляйте строку подключения в исходники и не отправляйте её в чат или GitHub.

### 2. Секреты приложения

Приложению нужны четыре переменные окружения:

| Имя | Где взять |
|---|---|
| `MONGODB_URI` | Строка подключения MongoDB Atlas |
| `ADMIN_LOGIN` | Придумайте логин для закрытого кабинета |
| `ADMIN_HASH` | Выполните локально `npm run create-admin-hash` и добавьте выведенный bcrypt-хеш |
| `SESSION_SECRET` | Сгенерируйте командой `node -e "console.log(require('node:crypto').randomBytes(48).toString('base64'))"` |

`ADMIN_HASH` — это хеш, а не пароль. Пароль не хранится в проекте. Не коммитьте `.env` или секреты: `.gitignore` уже исключает `.env`.

### 3. Контакты компании

Откройте `script.js` и заполните `SITE_CONFIG.phone` и `SITE_CONFIG.email`. Форма уже отправляет заявки на `/api/leads`; менять `formEndpoint` не требуется. Заявки сохраняются в MongoDB и доступны после входа в кабинет на `/admin/login`.

### 4. Локальный запуск

Нужен Node.js 20 или новее.

```powershell
npm install
Copy-Item .env.example .env
npm run create-admin-hash
npm start
```

Заполните созданный `.env` значениями из шагов 1 и 2. Откройте `http://localhost:3000`; кабинет находится по адресу `http://localhost:3000/admin/login`. Состояние входа хранится в MongoDB, а не в памяти процесса.

### 5. Публикация на Render

1. Загрузите проект в свой GitHub-репозиторий.
2. На Render создайте **New → Web Service** и выберите этот репозиторий.
3. Укажите **Build Command:** `npm install`, **Start Command:** `npm start`, **Runtime:** Node.
4. В настройках сервиса добавьте `MONGODB_URI`, `ADMIN_LOGIN`, `ADMIN_HASH`, `SESSION_SECRET` и `NODE_ENV=production`.
5. Дождитесь публикации и проверьте `https://ВАШ-ДОМЕН/healthz`, главную страницу, отправку тестовой заявки и `/admin/login`.
6. Подключите домен в Render и настройте HTTPS средствами хостинга.

Ключи MongoDB и сессии добавляются в **Render → ваш сервис → Environment**, а не в файлы проекта. Если приложение не запускается, проверьте Render Logs и точность переменных. Для нового деплоя можно использовать `npm install` и `npm start` именно как указано выше.

## Перед выходом сайта в продакшен

- В `index.html` замените демонстрационные визуализации и концепты на реальные проекты, укажите фактические услуги, регионы и условия строительства.
- Заполните все поля в квадратных скобках в `privacy.html`, укажите фактическое размещение базы, сроки хранения заявок, оператора и контакты. Сверьте документ с требованиями юрисдикции компании.
- Проверьте согласие в форме, размещение данных, доступ к MongoDB и контакты. Не публикуйте незаполненную политику.
- Сферические дома на сайте — оригинальная архитектурная концепция; название компании оставлено по предоставленному описанию. Проверьте право на использование выбранного названия и фирменных материалов.
